# 🥗 Cantine+

Application web de réduction du gaspillage alimentaire dans les cantines scolaires et d'entreprise, développée avec Python et Streamlit.

---

## 🚀 Lancer le projet en local

### 1. Cloner le projet

```bash
git clone https://github.com/aboubacre14/cantine-plus.git
cd cantine-plus
```

### 2. Installer les dépendances

```bash
pip install -r requirements.txt
```

### 3. Lancer l'application

```bash
streamlit run app.py
```

L'application s'ouvre sur **http://localhost:8501**

---

## 📌 Ce que tu trouveras dans l'app

- 📊 Dashboard cantine (gaspillage, participation, CO₂, coûts)
- 🍽️ Gestion des menus sur plusieurs semaines
- 👨‍👩‍👧 Espace Parent (votes, présence, allergies, feedback)
- 👦 Espace Élève (gamification, badges, points)
- 💼 Espace Entreprise (réservation, notation, dashboard RH)
- ♻️ Repas Solidaires (invendus à prix réduit)
- 🤖 IA Coach Enfant (génération de script audio motivant)

> Les données sont simulées, aucune configuration externe n'est nécessaire.
